# alertas-magallanes

Proyecto de aprendizaje para un portafolio de Computer Science. La especificación está en `SPEC.md`.

## Reglas de trabajo

- Responder siempre en español.
- Explicar cada decisión (por qué esta opción y no otra) y cada parte del código que se escriba.
- Trabajar un paso a la vez. Al terminar un paso, detenerse y esperar a que el usuario pida avanzar.
- Antes de implementar un paso, proponer un plan y esperar aprobación.
